# Inventory Cleanup

A client-side NeoForge 1.21.1 inventory UI cleanup mod.

## Features

- Removes the Curios launcher button and displays visible Curios equipment slots beside the player inventory.
- Clicking the inline Curios area opens Curios' equipment screen for full slot interaction.
- Removes the Apothic Attributes stats panel and its buttons from the player inventory.
- Hides the recipe book button only on the player inventory screen; crafting-table recipe books remain unchanged.
- Repositions the Reskillable tab to the top-left and adds a chest-icon Inventory tab before it.
- Optional Sophisticated Backpacks support: every backpack you carry (Curios slot, chest slot, offhand, inventory) gets its own tab after Inventory and Skills, using that backpack's item (dye, tier, etc.) as the icon. Clicking a tab opens that backpack. Tabs are listed in the same order the open-backpack keybind searches, so the first backpack tab is the one the keybind would open. The same tab row is shown above Sophisticated Backpacks' own screens.

Target: Minecraft 1.21.1, NeoForge 21.1.x. Curios, Reskillable, and Apothic Attributes are required integrations; Sophisticated Backpacks is optional.

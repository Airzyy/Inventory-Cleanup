# Inventory Cleanup

A client-side NeoForge 1.21.1 inventory UI cleanup mod.

## Features

- Removes the Curios inventory button and integrates accessory slots into the player inventory.
- Removes the Apothic Attributes stats button from the player inventory.
- Keeps Curios slots visible on the player inventory screen.
- Hides the recipe book button only on the player inventory screen; crafting-table recipe books remain unchanged.
- Repositions the Reskillable tab to the top-left and adds an Inventory tab before it.

Target: Minecraft 1.21.1, NeoForge 21.1.x.

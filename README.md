# Inventory Cleanup

A client-side NeoForge 1.21.1 inventory UI cleanup mod.

## Features

- Removes the Curios launcher button and displays visible Curios equipment slots beside the player inventory.
- Clicking the inline Curios area opens Curios' equipment screen for full slot interaction.
- Removes the Apothic Attributes stats panel and its buttons from the player inventory.
- Hides the recipe book button only on the player inventory screen; crafting-table recipe books remain unchanged.
- Repositions the Reskillable tab to the top-left and adds a chest-icon Inventory tab before it.

Target: Minecraft 1.21.1, NeoForge 21.1.x. Curios, Reskillable, and Apothic Attributes are required integrations.
